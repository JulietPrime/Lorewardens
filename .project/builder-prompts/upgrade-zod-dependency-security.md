## Breaking-change review (architect-verified inventory at develop a35b867)

Direct zod imports exist ONLY in `packages/mcp-server/src/tools.ts` and `packages/mcp-server/src/bootstrap.ts` (grep-verified across all packages; core/agents/bridge/proof/docs-extension import no zod). The complete API surface in use:

| # | API in use | Location | zod v4 verdict |
|---|------------|----------|----------------|
| 1 | `z.object({...})` | tools.ts (`AnalyzeToolInput`, `CanonListInput`), bootstrap.ts (`CanonBootstrapInput`) | Unchanged in v4 |
| 2 | `z.string().min(1).describe("...")` | multiple | Unchanged (`.describe()` is soft-deprecated in favor of `.meta()` in v4 but fully functional — KEEP as-is, do not churn) |
| 3 | `z.number().int().min(0)` | tools.ts chunk offsets | Unchanged |
| 4 | `z.enum([...]).optional()` | tools.ts `strictness` | Unchanged |
| 5 | `z.discriminatedUnion("kind", [...])` + `z.literal(...)` | bootstrap.ts `source` | Unchanged (v4 relaxes, not breaks) |
| 6 | `z.string().datetime().optional()` | bootstrap.ts `generatedAt` | **DEPRECATED in v4 — migrate to `z.iso.datetime()`** (identical RFC 3339 semantics; offsets still rejected by default). This is the ONE required code change. |
| 7 | `z.ZodTypeAny` (type annotation on `ToolDef.inputSchema`) | tools.ts:52 | Still exported in v4 (deprecated alias) — KEEP |
| 8 | `.parse()` | tools.ts:65, tools.ts:132, bootstrap.ts:115 | Unchanged. ZodError message STRINGS changed format in v4 ("Invalid input: expected ..."), but no test in this repo pins any zod error message (grep-verified), so no assertion is affected |

Verified NOT present anywhere in the repo (so none of v4's removed/renamed APIs need attention): `z.record`, `.errors` / `.issues` consumers, `.flatten()` / `.format()` / `errorMap`, `invalid_type_error` / `required_error`, `superRefine`, `nativeEnum`, `.strict()` / `.passthrough()` / `.catchall()`, `z.promise`, `z.function`, `.nonempty()`. Do not make speculative changes beyond the inventory.

Dependency graph (verified in package-lock at base):

- `@modelcontextprotocol/sdk` resolves 1.32.2 and declares zod both as peer and dependency with range `"^3.25 || ^4.0"` — already supports v4. DO NOT change the SDK version.
